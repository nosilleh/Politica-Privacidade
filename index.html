Política de Privacidade

Esta Política de Privacidade descreve como as informações são tratadas ao utilizar o aplicativo Alarme Motivacional.

1. Coleta de informações

O aplicativo não coleta dados pessoais identificáveis, como nome, e-mail ou número de telefone.

2. Anúncios

O aplicativo exibe anúncios por meio de serviços de terceiros, como o Google AdMob. Esses serviços podem coletar dados não pessoais, como identificadores do dispositivo e dados de uso do aplicativo.

3. Notificações

O aplicativo utiliza notificações locais exclusivamente para o funcionamento do alarme, avisando o usuário no horário programado.

4. Crianças

O aplicativo pode ser utilizado por crianças menores de 13 anos. Não há coleta intencional de dados pessoais de crianças.

5. Compartilhamento de dados

O aplicativo não compartilha dados pessoais com terceiros, exceto dados não pessoais necessários para a exibição de anúncios.

6. Segurança

São adotadas medidas razoáveis para proteger as informações utilizadas pelo aplicativo.

7. Alterações

Esta política pode ser atualizada periodicamente.
